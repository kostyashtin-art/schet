# Мой бюджет — версия на чистом JavaScript

Статический сайт без React, TypeScript, Vite, npm и процесса сборки. GitHub Pages может отдавать его напрямую из корня репозитория.

## Публикация в GitHub Pages

1. Распакуйте архив.
2. Замените **все файлы в корне** репозитория `88888888` содержимым архива. Файл `index.html` должен лежать прямо в корне.
3. В GitHub откройте **Settings → Pages**.
4. В разделе **Build and deployment** установите **Deploy from a branch**, ветка `main`, папка `/(root)`, нажмите Save.
5. Откройте `https://kostyashtin-art.github.io/88888888/` и обновите страницу через Ctrl+F5.

Не нужен GitHub Actions и не нужны команды npm.

## Подключение Supabase

В файле `config.js` уже указан URL проекта. Вставьте свой публичный ключ в `supabaseKey`:

```js
window.BUDGET_CONFIG = {
  supabaseUrl: "https://hxctmmmglttocjwwbppz.supabase.co",
  supabaseKey: "ВСТАВЬТЕ_ПУБЛИЧНЫЙ_PUBLISHABLE_ИЛИ_ANON_KEY"
};
```

Ключ берётся в Supabase → Project Settings → API / API Keys. Используйте только публичный `publishable` или legacy `anon` key. Никогда не вставляйте `service_role` или `sb_secret` ключ в браузерный проект.

SQL для таблицы операций и политик доступа находится в `supabase/schema.sql`. Если вы уже выполняли этот SQL в проекте Supabase, повторно запускать его обычно не нужно.

## Возможности

- регистрация и вход по email через Supabase Auth;
- облачное хранение операций с учётом RLS;
- ручное добавление и удаление доходов/расходов;
- обзор по месяцу и баланс;
- диаграммы доходов и расходов по месяцам;
- поиск и фильтрация операций;
- импорт Excel с предварительным просмотром;
- экспорт CSV и JSON, восстановление из JSON.

Примечание: Excel импортирует строки, где есть распознаваемая колонка суммы и дата. Формулы не пересчитываются приложением. Всегда проверьте предварительный просмотр перед импортом.
